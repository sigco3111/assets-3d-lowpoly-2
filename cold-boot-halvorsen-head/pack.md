# Cold Boot 할보르센 3D 머리 (MakeHuman CC0)

브라우저 FPS 호러 COLD BOOT의 레벨 3 인물 할보르센의 머리 GLB입니다. 사진 스캔이 아니라 MakeHuman 1.x의 CC0 데이터(베이스 메시·모프 타깃·스킨·눈썹)를 원작자의 자체 스크립트로 변형해 만든 약 58세 남성의 머리입니다(14,783 버텍스, 768x1280 컬러+노멀 맵, 971KB, 디코더 불필요).

**라이선스: CC0 1.0.** 귀속 표기 의무는 없지만 아래 크레딧을 권장합니다. CC0는 저작권만 포기하며 초상권과는 무관합니다(스톡 스킨을 변형해 특정 인물을 재현하지 않는다는 원작 설명이 docs/ASSETS.md에 있습니다).

## 내용 (zip)

- `halvorsen-head.glb` — 스키닝된 머리 모델 (head/jaw/brow/neck 본)
- `LICENSE-CC0-1.0.txt` — CC0 1.0 전문
- `LICENSE-SOURCE.txt` — 수집자 작성 출처·라이선스 근거

## 활용 메모

- 실패 시 절차적 머리로 폴백하는 구조였기 때문에 단독 로드가 가능합니다(GLTFLoader).
- 크레딧 라인: Halvorsen's head is built from MakeHuman assets (base mesh, morph targets, skin, eyebrows) by the MakeHuman team, www.makehumancommunity.org, released CC0 1.0, modified.
